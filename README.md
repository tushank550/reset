# Us, Reset ♡

A light, romantic, phone-first relationship reset website with a personal photo/memory section.

### Files
- `index.html`
- `style.css`
- `script.js`
- `photos/` — the five photos used in the memory section

### GitHub Pages
Upload everything to a repository, keeping the `photos` folder intact.

Then:
**Settings → Pages → Deploy from a branch → main / root → Save**

The memory section is horizontally swipeable on phones.
